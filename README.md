1. What it does. One paragraph: monitors and controls Braiins OS miners in Home Assistant.
2. Features. List the entities and controls your integration provides.
3. Tested with. Antminer S19e XP, Home Assistant 2026.9. Be honest that other models are untested.
4. Installation via HACS. HACS → three-dot menu → Custom repositories → paste the repo URL → category Integration → Add → find "Braiins OS" → Download → restart Home Assistant.
5. Manual installation. Copy custom_components/braiins_os into your HA config/custom_components/ folder and restart.
6. Setup. Settings → Devices & Services → Add Integration → "Braiins OS" → enter miner IP and credentials.
7. Disclaimer. Unofficial, not affiliated with Braiins, and changing power targets or settings on mining hardware is at your own risk.
